# Webサイト / システムの内容

小売・ECの売上データを対象に、売上、粗利、目標達成率、チャネル別比率、地域別売上、カテゴリ別収益性を可視化するBIダッシュボードを作成しました。
期間、地域、商品カテゴリ、販売チャネルで絞り込み、KPI、月次推移、地域×カテゴリのヒートマップ、明細テーブル、自動インサイトが連動して更新されます。

## システム構成

- 入力データ: 販売データ、注文数、目標、欠品数、返品数、広告費のサンプルデータ
- 集計処理: JavaScriptでフィルタ条件に応じた売上、粗利、目標達成率、欠品率、返品率を算出
- 可視化: HTML / CSS / SVGでKPIカード、折れ線グラフ、ドーナツチャート、ヒートマップ、明細テーブルを表示
- 出力: 現在の絞り込み条件でCSV出力、実績説明文のコピー

構成図:

販売データ(CSV / 基幹データ想定) → JavaScript集計処理 → HTML/CSS/SVG可視化UI → 分析・CSV出力

## Webサイトやシステムのイメージ

ローカルHTMLとして作成しています。
公開URLが必要な場合は、このフォルダをGitHub Pages、Vercel、Netlifyなどへ配置するとWeb URLとして共有できます。

## 作成にあたってこだわった点、注意した点

- 売上だけでなく、粗利率、欠品率、返品率、目標達成率を同時に見られるようにし、利益面と運用面の判断ができる画面にした。
- フィルタ操作後にKPI、グラフ、テーブル、自動インサイトが一括で更新されるようにし、分析時の手戻りを減らした。
- 地域×カテゴリのヒートマップを入れ、どの領域に注力すべきか視覚的に分かるようにした。
- 外部ライブラリなしで動く静的Webアプリにし、ポートフォリオとして公開しやすい構成にした。
- スマートフォンでも確認しやすいように、サイドバー、KPIカード、グラフ、テーブルの表示をレスポンシブ対応にした。

## 実績欄に書く例

小売・ECの売上分析を想定したBIダッシュボード「Retail Pulse BI」を制作しました。販売データをもとに、売上、粗利、目標達成率、チャネル構成、地域別売上、カテゴリ別収益性を可視化し、期間・地域・カテゴリ・チャネルで絞り込めるようにしました。特に、売上だけでなく粗利率や欠品率も同時に確認できるようにし、現場担当者が次の施策を判断しやすい画面構成を意識しました。HTML、CSS、JavaScript、SVGのみで動作する静的Webアプリとして作成し、CSV出力や説明文コピーにも対応しています。
